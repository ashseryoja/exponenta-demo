# ZUNO — Զգա քո ուժը։

Сайт: https://exponenta-demo.vercel.app/

Самостоятельный интерактивный концепт бренда ZUNO: вступительная анимация, 3D-модель, параллакс, ручное и автоматическое вращение, карточка продукта и визуальные ритм-секции.

## Запуск

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

Открыть http://127.0.0.1:5173/ . Сборка: `npm run build`, статические файлы — `dist/client`.

## Материалы

- `public/assets/zuno-cup.glb` — 3D-модель продукта.
- `public/assets/zuno-mark.svg` — оригинальный SVG-знак ZUNO.
- Интерфейс на армянском. Noto Sans Armenian Black — заголовки; Montserrat Armenian — основной текст и навигация. Армянские шрифты подключены локально. Источники: `public/fonts/NOTICE.md`.
- Это локальный демонстрационный сайт без корзины и платёжной системы.

Анимация: вращающийся выход модели из заставки, покачивание и реакция на курсор, семь поз при прокрутке с первого пикселя. Нажатие на модель (или Enter/пробел) запускает полный оборот с подскоком.

Управление: перетаскивание модели мышью/пальцем, стрелки клавиатуры при фокусе на модели; кнопки вращения и сброса во второй секции. Кнопка внизу повторяет заставку. При отключённом WebGL показан нейтральный знак ZUNO, анимации учитывают `prefers-reduced-motion`.
