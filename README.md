# EXPONENTA — Զգա քո ուժը։

Сайт: https://ashseryoja.github.io/exponenta-demo/

Публикация: GitHub Pages. Изменения в `main` автоматически собираются и публикуются через GitHub Actions. Для сборки по адресу репозитория используется `VITE_BASE_PATH=/exponenta-demo/`.

Небольшой интерактивный прототип бренда: вступительная анимация, предоставленная 3D-модель, параллакс, ручное вращение, автоматическое вращение, карточка продукта и фотографии Instagram.

## Запуск

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

Открыть http://127.0.0.1:5173/ . Сборка: `npm run build`, статические файлы — `dist/client`.

## Материалы

- `public/assets/exponenta.glb` — предоставленная пользователем модель.
- Фотографии и логотип из [Instagram бренда](https://www.instagram.com/exponenta.am/).
- Один реальный вкус: малина–банан. Другие этикетки и варианты не имитируются.
- Базовая модель: около 240 тысяч треугольников, 12.6 MB. Для большого публичного запуска желательно дальнейшее упрощение сетки и сжатие.
- Интерфейс на армянском. Noto Sans Armenian Black — заголовки; Montserrat Armenian — основной текст и навигация. Армянские шрифты подключены локально. Unbounded используется для латинского названия бренда и чисел. Источники: `public/fonts/NOTICE.md`.
- Это локальный демонстрационный сайт без корзины и платёжной системы.

Анимация: вращающийся выход модели из заставки, заметное покачивание и реакция на курсор, семь поз при прокрутке с первого пикселя. Нажатие на модель (или Enter/пробел) запускает полный оборот с подскоком.

Управление: перетаскивание модели мышью/пальцем, стрелки клавиатуры при фокусе на модели; кнопки вращения и сброса во второй секции. Кнопка внизу повторяет заставку. При отключённом WebGL показана фотография, анимации учитывают prefers-reduced-motion.
